# BUG-004 — Emulador e backend usavam project IDs diferentes

**Origem:** OBS-04 do registro do PO (01/11/2026)
**Critério afetado:** CT-M02 (autenticação real no emulador)
**Severidade:** Alta — login impossível no ambiente local
**Estado:** **Fechado** — corrigido no commit `9e8275f`
**Responsável:** DevOps (#13) com TL (#18)

## Passos para reproduzir

1. Subir o Compose e conferir o nome do projeto no início do emulador.
2. Tentar login com a conta sintética provisionada para `demo-carbontrace`.

## Esperado

Um projeto local coerente entre emulador, backend e script de seed.

## Obtido (antes da correção)

O emulador iniciava como `demo-no-project`, o backend usava `demo-carbontrace` e o login
retornava `EMAIL_NOT_FOUND`. A conta existia — em outro projeto.

## Causa raiz — confirmada no CI

`initialize_app()` **sem opções não lê `FIREBASE_PROJECT_ID`**. Esse nome é convenção do
projeto, não do SDK. O Admin SDK procura o projeto em (a) credencial de serviço ou
(b) `GOOGLE_CLOUD_PROJECT`; sem nenhum dos dois:

`ValueError: A project ID is required to access the auth service`

Foi exatamente o que derrubou o job `deny-all` do PR #30.

## Correção aplicada (commit `9e8275f`)

- `PROJETO = os.environ.get("FIREBASE_PROJECT_ID", "demo-carbontrace")`
- `initialize_app(options={"projectId": PROJETO})`
- em `main()`: `os.environ.setdefault("GOOGLE_CLOUD_PROJECT", os.environ["FIREBASE_PROJECT_ID"])`

## Nota sobre o Plano Custo Zero

`GOOGLE_CLOUD_PROJECT` **não** é uso de GCP: é variável de ambiente local no runner. O
valor `demo-carbontrace` usa o prefixo `demo-`, convenção documentada do Firebase que
sinaliza projeto inexistente e força o código a falar só com o emulador
(`127.0.0.1:8080`). Sem requisição a `googleapis.com`, sem cota, sem faturamento.

## Verificação

Job `deny-all` do CI verde após o commit, com os 9 casos executando.

## Observação de método

Este defeito tem três descobertas do mesmo problema: o PO em 01/11 (OBS-04), o CI em
03/11 (job vermelho) e a correção final. A correção foi verificação real, não tentativa.

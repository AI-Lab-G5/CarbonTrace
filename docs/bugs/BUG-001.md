# BUG-001 — Jornadas J1–J3 não percorríveis pela interface

**Origem:** OBS-01 do registro do PO (01/11/2026)
**Critério afetado:** CT-M01, CT-M03, CT-M05
**Severidade:** Alta — bloqueia a demonstração do CP2
**Estado:** Aberto
**Responsável:** Frontend (#9, #19) com integração de Backend (#11)

## Passos para reproduzir

1. Partir de um checkout limpo do `main` (`5a35330`).
2. `docker compose -p carbontrace up --build -d`
3. Abrir `http://localhost:3000`.
4. Procurar login, cadastro de loja, vínculo de fonte e registro de consumo mensal.

## Esperado

Executar J1 (cadastrar unidade e fonte), J2 (registrar consumo validado) e J3
(calcular com fator versionado) autenticado como `funcionario`.

## Obtido

A interface oferece apenas uma calculadora didática e a consulta de disponibilidade da
API. Não há tela de login, de unidades, de vínculo de fontes nem de lançamento mensal.
O resultado da calculadora desaparece ao recarregar a página.

## Ambiente

`main` @ `5a35330`, Linux, Docker Compose, Firebase Emulator Suite.

## Impacto

O aceite do CP2 depende de demonstração ponta a ponta. Sem a jornada, os 182 testes de
backend provam a API mas não o produto.

## Evidência

`documentacao/assets/cp2-po-interface-2026-11-01.png`

## Observação de escopo

O frontend com o percurso integrado existe na branch `dev` (PR #27) e não foi integrado
à `main`. Enquanto os branches não convergirem, este bug permanece aberto para a `main`.
